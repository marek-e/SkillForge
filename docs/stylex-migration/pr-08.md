## The finding that mattered: a class name can be load-bearing

`Button` sizes the icons inside it with `[&_svg:not([class*='size-'])]:size-4` — or `size-3.5` at
the `sm` size — and `EmptyMedia`'s icon variant does the same. That selector does not look at the
child's computed size; it looks at the **literal text of its `class` attribute**.

`Spinner` rendered `size-4 animate-spin`, so it matched `[class*='size-']` and the container left
it alone. A spinner whose classes were StyleX hashes does not match, and the container resizes it.
Measured, with the size moved into `stylex.create` and the class dropped:

| Case                   | Before | After |
| ---------------------- | ------ | ----- |
| `spinner-frame-target` | 16px   | 16px  |
| `spinner-in-button`    | 16px   | 14px  |

So `size-4` stays a Tailwind class on `Spinner` — not because a caller contests it, but because
its own name is part of the contract with every ancestor that writes a `[class*='size-']` rule. It
goes when those rules do, in PR 32. **Every component that renders an icon of its own is exposed
to this**; it is now in [`conventions.md`](conventions.md).

## The two keyframes

`animate-pulse` and `animate-spin` become `stylex.keyframes` with Tailwind's frames, duration,
timing function and iteration count copied from [`tailwind-values.md`](tailwind-values.md) §8:

| Utility         | Frames                             | Duration | Timing                         |
| --------------- | ---------------------------------- | -------- | ------------------------------ |
| `animate-pulse` | `50% { opacity: .5 }`              | `2s`     | `cubic-bezier(0.4, 0, 0.6, 1)` |
| `animate-spin`  | `to { transform: rotate(360deg) }` | `1s`     | `linear`                       |

**`animation-name` is the one computed value this migration cannot keep.** StyleX hashes the
keyframes (`xjsmpz5-B`, `x1fy8ia8-B`), so the name differs from Tailwind's `pulse` and `spin`. It
is therefore left out of the computed-style dumps, and the curve itself is pinned two other ways:
the longhands (`animation-duration`, `animation-timing-function`, `animation-iteration-count`,
`animation-direction`, `animation-fill-mode`) are snapshotted, and six new PNG originals capture
the two elements at 0 ms, 500 ms and 1000 ms.

A side effect worth knowing: `animation: …` is a shorthand and the StyleX version is five
longhands, so the two differ for any property the shorthand would reset (delay, direction,
fill-mode, play-state). All of them are at their initial value in both, which is what the
snapshot checks.

## Infinite animations make a computed-style dump non-deterministic

The first `computed-feedback-*.json` run came back with `opacity: 0.643146` and its neighbours
disagreeing run to run: a `Skeleton` is mid-pulse whenever the dump happens to run. The two
feedback tests now call `installAnimationFreeze` + `freezeAnimationsAt(page, 0)` before
collecting, which is also the frame every other screenshot in the suite parks them on. The same
effect shows up in the live probe, where it is the only difference between the two trees and is
reported as such.

## Smaller things

- `flex-1` is `flex: 1` in Tailwind v4, not `1 1 0%`.
- `max-w-sm` is `var(--container-sm)` = `24rem`.
- `text-sm/relaxed` is `0.875rem` over the named relaxed step, **1.625 unitless** — a ratio in
  Tailwind too, so writing it as one keeps inheritance identical. The paired-line-height trap does
  not apply to a slash modifier.
- `tracking-tight` is `-0.025em`.
- `bg-transparent` is `#0000`; `transparent` computes to the same `rgba(0, 0, 0, 0)`.
- `Empty`'s `border-dashed` sets a style for a border that has no width. Kept, invisible.
- `Alert`'s `relative` is written twice (unconditionally and as
  `has-data-[slot=alert-action]:relative`); one `position: relative` covers both.
- `has-[>svg]:gap-x-2` is a `column-gap` longhand against the `gap` shorthand, which StyleX ranks
  below it — the same outcome Tailwind gets from (0,2,0) against (0,1,0).
- `px-2.5` / `pr-18` on `Alert` follow PR 07's logical-versus-physical rule: `padding-inline` for
  the pair, the physical longhand for the single side.
- This repo's `alert.tsx` is a newer shadcn revision than the migration plan's row text assumed:
  it has `has-[>svg]:grid-cols-[auto_1fr]` and `*:[svg]:row-span-2` rather than
  `grid-cols-[0_1fr]` and `[&>svg]:size-4`, and only `AlertTitle` carries a `col-start-2`. What is
  in the file is what was translated.

## Observed pre-existing defects

Nothing was fixed. In addition to the lists in [`pr-00.md`](pr-00.md), [`pr-04.md`](pr-04.md),
[`pr-05.md`](pr-05.md), [`pr-06.md`](pr-06.md) and [`pr-07.md`](pr-07.md):

  the bundle unused by any route.
