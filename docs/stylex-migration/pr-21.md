# PR 21: App sidebar, project avatars, and editor selection

## Scope

Migrates `app-sidebar/*`, `project-avatar.tsx`, and `EditorSelect.tsx` without changing
DOM order, navigation, editor persistence, avatar selection, or the unused `layout` prop's
existing behavior. The sidebar icon state uses its existing `data-slot` and
`data-collapsible` attributes. NavUser keeps its existing open, hover, and active colors.

The caller override channel is now `sx` on Avatar/Image/Fallback, SelectTrigger,
InputGroup/InputGroupInput, Input, and DropdownMenuContent/Label. EditorSelect exposes
`triggerSx` and `inputSx`; settings, project overview, and gallery widths use these channels.
Its former trigger height override was inert: the default size's conditional height
already made the trigger 32px tall, so the migration preserves 32px.

## Baseline and coverage

Originals remain frozen at `ee0f797`, Playwright 1.63.0 / Chromium 153.0.8010.12,
with the existing light/dark and desktop/mobile fixtures. No original was changed.
Existing `gallery app` cases cover every project-avatar size, custom icons, and editor
choices. `app-sidebar-migration.spec.ts` adds interaction checks for navigation active
states, favorites, custom-command trimming, and editor preference persistence.

## Final bridge removal

The same recovery pass completes form primitives needed by the final migration:
Input, Textarea, Label, InputGroup, ButtonGroup, Field, and Avatar. Their remaining
utility constants and cva helpers become StyleX declarations and explicit prop unions.
Every styled export accepts `sx`, while selector-only group, peer, and explicit icon-size
markers remain. Descendant rule classes compose separately from own-box overrides so
changing a component width cannot delete its icon or child-width rules. Paired inherited line heights use the shared StyleX typography variables.
Form rings keep the original five-layer shadow chains, including the zero-width colored
ring of grouped controls.

## Validation

Targeted lint passes on the owned components and new interaction spec. Vite production
compilation passes. All eight app-sidebar interaction tests pass across both viewport sizes and themes.
The frozen computed-style matrix passes all 128 tests across the complete run and targeted
reruns after caller corrections. Five same-machine original comparisons also pass: app and
skills-extra galleries in both themes, plus invalid-input focus states. The remaining
dev/production visual gates are recorded with the final migration audit.

The host OS differs from the original capture environment. The parent audit checks this
against the untouched frozen app before attributing any screenshot difference to styling.
