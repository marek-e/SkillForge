# PR 20: app shell, titlebar and breadcrumbs

Migrated `Layout`, `electron-titlebar`, `mode-toggle`, `ErrorContainer` and
`lib/breadcrumbs.tsx` to StyleX. `BreadcrumbItem`, `BreadcrumbPage` and
`BreadcrumbSeparator` accept an `sx` override so callers compose display styles
after the component defaults. The existing DOM, labels and handlers stay intact.

The frozen reference remains `ee0f797`, Playwright 1.63.0 and Chromium
153.0.8010.12, build v1243. New `shell-migration.spec.ts` cases captured 24 new
originals before changing the shell source. They cover both themes and viewport
projects, the header and theme menu, icon transforms, Windows close-button hover
with both pointer types, button geometry, and Electron drag regions.

Baseline verification passed all eight new tests. After migrating, their PNGs
matched exactly. Their computed JSON found that lightningcss lowered a zero angle
to `none`; an explicit project custom-property fallback preserves the original
computed `0deg`. All eight cases then passed, including the computed reports.

Commands:

```sh
VISUAL_PORT=4388 pnpm exec playwright test visual/shell-migration.spec.ts --workers=2 --output=/tmp/skillforge-shell-results --reporter=line
pnpm --filter @skillforge/ui typecheck
```

`WebkitAppRegion` now belongs to the titlebar and controls. The `.drag` and
`.no-drag` strings remain semantic markers, including the existing Electron test
selector, and need no global stylesheet rule. `.electron-app` also remains the
existing shell marker. This row leaves no Tailwind styling class in its owned
application files. The shared breadcrumb primitive retains its previously
documented icon and inherited-font bridges until the final removal step.

The parent migration runs the complete development and production suites and
native Electron checks after integration. Those checks are not claimed here.
