## What became StyleX, and what stays Tailwind

`space-y-*` migrates for the PR 22/26/27 reason — every child it reaches is one of this route's own
boxes or a StyleX component with no block margin of its own — and the three `text-*` are leaf text
nodes, so each paired line height is the length (`0.75rem`/`1rem`, `0.875rem`/`1.25rem`).
**No `sx` was added or needed**: `Button` and `Label` are the two components here that expose one
(`Separator` is unused) and the route hands neither a `className`; `Input`, `Textarea`, `Badge` and
`Skeleton` have none, so their overrides stay `className` bridges in constants PR 32 removes.

## Findings

- **A comment word becomes a rule even when it describes the bug the comment is about.** The first
  draft explained that hashing `size-4` would let the button _reduce_ the icons, using the plain
  English verb for that; the verb is a Tailwind utility name, and the built CSS gained
  `.flex-shrink,.shrink{flex-shrink:1}` — PR 24's trap in a new shape, caught only by the byte-for-byte
  comparison of the Tailwind portion.
- **One atomic class for the whole route**: `grid-template-columns: repeat(2, minmax(0, 1fr))`. The
  three `space-y-*` pairs, both gaps, the two muted `text-*` and the mono stack dedupe onto PR 22–27.
- **This route has no breakpoint at all**, so none of the media-query ordering the two previous route
  rows reasoned about applies: `grid-cols-2` holds at 320px as at 1440px. Its one invisible state is
  the other kind — `flex-wrap` on the badge row, which does not wrap at either project width (three
  items at ~280px against 358px of content box at 390px).

## Observed pre-existing defects (nothing was fixed)

- **The `text-2xl` name field renders at 14px on desktop.** `input.tsx` keeps `md:text-sm` as a
  Tailwind class, and a media query emitted after the caller's `text-2xl` wins at the same
  specificity, so the title is 24px only below 48rem. It is what the originals froze, and it goes
  away when PR 32 deletes the contested classes — verify the 24px there.
- **The two-column field row never collapses** (`grid-cols-2` has no breakpoint, so `Scope` and `Tags`
  sit in two 171px columns at 390px); **`DeleteSkillDialog` is mounted unconditionally**.

## Findings for conventions.md

- **The scanner reads prose, not just class-shaped tokens** — PR 24 said as much for `shrink` and
  `resize`; this row hit the same word while _describing_ the hazard. The check is "grep the comment's
  words against the utility names", not "avoid writing class names".
- **A route with no media query still has an invisible state.** The previous route rows needed a width
  band for a breakpoint; this one needs 320px because `flex-wrap` never wraps at 1440 or 390. Any
  width-dependent declaration, not only a `@media` one, is outside the two-viewport matrix.
