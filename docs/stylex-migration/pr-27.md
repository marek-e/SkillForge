## Findings

- **`space-y-*` migrated, `divide-y` did not, and the line is who renders the child.** Same shape,
  same trade of a (0,1,0) selector for a (0,2,0) one in a `priorityN` layer — but `space-y-*` here
  reaches only elements this route renders or two StyleX components with no block margin of their
  own, while `divide-y` writes a border onto an element `SkillCard` owns.
- **Two breakpoints on one property must be nested, not siblings.** StyleX prices a condition by
  nesting depth, so `sm:` and `lg:` as sibling `@media` keys tie, and the tie goes to whichever
  module first emitted the declaration. Nested, the compiler emits
  `@media (width >= 64rem) { @media (width >= 40rem) { .x.x.x { … } } }` against the outer `.x.x`.
- **`marginBlockStart: '0rem'` and `space-y-2` cost nothing**: both dedupe onto classes `ToolCard`
  emitted in PR 22, so ten new styles add six atomic classes. And a caller's **`text-xs` and
  `badge.tsx`'s own `0.75rem`/`1rem` land on the same `12px`/`16px` line box**, so the
  `calc(1 / 0.75)` ratio is not the rounding trap PR 03 found.

## Gallery and new cases

**No gallery section was added.** Every state the fixtures reach is already covered by
`route skill-library {populated,empty,loading,error} × {light,dark}` and the `skill library grid
mode` pair from PR 00, all left byte-identical. The one route-local state neither project reaches
is the grid's middle breakpoint — one column at 390px, three at 1440px, so the two-column band is
never captured, and it is where a wrong media-query order would hide. A gallery case cannot reach
it either: a gallery section is laid out by the viewport the project fixes. So the case sets its
own width in an appended `routeslib grid breakpoint` block of `routes.spec.ts` — two tests at
800×900, a full-page and a scrolled shot in both projects, 8
originals captured with `--update-snapshots=missing` on the clean `87a01ad` base **before** the
route was touched and re-run green on it. `-g routeslib` selects exactly them.

## Findings for conventions.md

- **Two breakpoints on one property need a nested condition, not two sibling `@media` keys** — the
  selector-mapping table's `sm:`/`md:`/`lg:` row is worth a sentence saying so.
- **The foreign-element rule splits the `:where(& > :not(:last-child))` family by who renders the
  child, not by the utility.** PR 22 migrated a `space-y-*`, PR 23 kept one; this route has one of
  each side by side.
- **A route's own viewport breakpoints cannot be covered by a gallery case** — a gallery section is
  laid out by the viewport the project fixes, so such a state needs a spec case with its own
  `setViewportSize`. Worth a line next to "Gallery cases are append-only per section".
