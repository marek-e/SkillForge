## What became StyleX, and what stays Tailwind

`stylex.create` covers every element the route renders itself: the `space-y-6` page wrapper, the
`flex items-start justify-between` header, the `space-y-2` title stack, the

| ------------------------ | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `h-12 w-full rounded-lg` | the three loading `Skeleton`s | `Skeleton` is StyleX but takes no `sx` prop, so a caller's size still arrives as a `className` its `cn` appends — which is also what keeps it winning, since `@layer utilities` sits above every `priorityN` layer (`SKELETON_CLASSES`, PR 32) |

## Findings

- **This kept `className` is load-bearing, unlike PR 27's.** `skeleton.tsx` declares `rounded-md`
  (`8px`) in StyleX and the caller's `rounded-lg` (`10px`) overrules it from outside; PR 27 kept a
  `text-xs` that only repeated `badge.tsx`'s own size. With no `sx` prop and no way for a
  `priorityN` rule to outrank a utility, a `className` bridge is the only channel that can win.
- **A caller's icon size can migrate when the `[class*='size-']` contract is variant-gated.** The
  `size-10` on `FolderOpenIcon` is the shape `combobox.tsx` had to keep as `CHEVRON_SIZE_CLASS`.
  Here it does not apply: `empty.tsx` adds `[&_svg:not([class*='size-'])]:size-4` **only** for
  `variant="icon"`, and this `EmptyMedia` takes the default variant, whose child rules are
  `[&_svg]:pointer-events-none [&_svg]:shrink-0`. With no utility left on the `<svg>`, the StyleX
  width/height/colour win unopposed; `route projects empty × {light,dark} × {desktop,mobile}` is
  the gate on that reading.
- **Eight styles cost three atomic classes** — only `padding-block: 2rem`, `margin-bottom: 1rem`
  and `1.5rem` are new (1017 → 1020); the rest dedupe onto classes PRs 18–23 emitted. **All three
  `space-y-*` migrated**, unlike the split PR 27 found: each reaches only elements this route
  renders, plus two dialogs that render nothing in the flow, so the last-child target is the same
  element in both forms. **`py-8` stays `paddingBlock`**, Tailwind's own property, so the paragraph
  does not start beating a caller's `py-*`.

## Findings for conventions.md

- **A kept `className` bridge is worth a word on whether it is redundant or load-bearing.** PR 27's
  `text-xs` repeated the component's own size; this row's `rounded-lg` overrules `skeleton.tsx`'s
  `rounded-md`. Only the second would change pixels if PR 32 dropped it.
- **"A class name can itself be the contract" needs the variant caveat.** `[class*='size-']` rules
  are often gated on a variant (`empty.tsx` applies its only for `variant="icon"`), so a caller's
  `size-*` can migrate whenever no _reachable_ rule reads the class text — the check is which
  branch renders, not whether the file contains such a selector.
- **A route with no breakpoint still has states no fixture reaches.** PR 27's line about viewport
  bands generalises: the trigger is any branch the _route_ decides, viewport or not.
