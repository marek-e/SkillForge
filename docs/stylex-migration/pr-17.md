# PR 17: sidebar

The sidebar primitives now use StyleX. The recovered sidebar gallery, interaction tests,
and frozen originals from the unfinished `pr-17` worktree remain intact.

The frozen application baseline is `ee0f797`, with Playwright 1.63.0 and Chromium
153.0.8010.12, build v1243. The current host runs Darwin 27; the original captures
used Darwin 25, so the final audit separately checks host rendering differences.

## Changes

- Migrated every sidebar branch and menu primitive, including fixed containers,
  responsive gaps, off-canvas rails, floating/inset variants, badges, submenus,
  focus rings, hover states, collapsed overrides, and pseudo-elements.
- Added `sx` overrides, composed last, while preserving inline style merging and
  the existing component props, state, event handlers, DOM, and data attributes.
- Moved Electron offset declarations onto the provider, container, and rail.
  The corresponding global rules can be removed by the final migration step.
- Preserved the separator's orientation-dependent width, the mobile sheet's
  original 75% width, and the clipped mobile header's original padding. The
  vertical separator has a 16px border box because its 1px width is smaller
  than its combined 16px horizontal padding.
- Preserved important collapsed menu dimensions and padding. Large collapsed menu
  buttons still use zero padding, as the original later important rule specified.
- Replaced inherited small text metrics with project-owned typography variables.
- Removed `cva`, `cn`, and all sidebar utility styling classes.

Only semantic `group`/`peer` marker classes remain. Icon-sizing contracts elsewhere
continue to recognize the explicit-size marker. Sidebar input and skeleton leaf
styles now use their components' `sx` props.

## Verification

The eight `computed styles sidebarx` cases passed against the unchanged frozen JSON
originals, including light/dark, desktop/mobile, and simulated Electron geometry:

```sh
VISUAL_PORT=4387 pnpm --filter @skillforge/ui exec playwright test \
  visual/computed-styles.spec.ts -g sidebarx --workers=1 --max-failures=1 \
  --output=/tmp/skillforge-sidebar-final2-computed --reporter=line
```

This check caught and corrected the inset shadow's no-op layers, the off-canvas
rail selector order and hidden scrollbar styling. The final pure-baseline
audit exposed a vertical-separator error inherited by the unfinished worktree
originals from an intermediate migration; its correction is recorded separately.
The standalone Vite build also compiled the important StyleX declarations.

The orchestrating final migration performs the full dev/production visual suites,
production build, repository checks, and live web/Electron verification after the
remaining rows and gallery conversion have finished.
