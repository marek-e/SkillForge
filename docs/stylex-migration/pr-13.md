## The animation is the whole job

Both files carry the same ten animation utilities: the `data-open:` / `data-closed:` pair of
`animate-in` / `animate-out`, `fade`, `zoom` and one `slide-in-from-*-2` per side. `tw-animate-css`
has **one** `enter` keyframe set whose `from` frame reads six custom properties and each utility
sets only one of them ([`tailwind-values.md`](tailwind-values.md) §10): `--tw-enter-opacity`,
`--tw-enter-translate-x/y`, `--tw-enter-scale`, `-rotate`, `-blur`. StyleX has no indirection, so each
combination becomes its own `stylex.keyframes` with the variables substituted and the no-op slots
spelled out: a plain `enter`, four directional ones (`translate3d(0, ∓0.5rem, 0)` /
`(∓0.5rem, 0, 0)`, keyed off `data-side`), and an `exit` whose translate stays at zero because
neither file sets a `slide-out-to-*`; all six carry `scale3d(.95,.95,.95) rotate(0) blur(0)`. The
composed `animation` shorthand becomes five longhands plus `animation-name`, the one computed value
this cannot keep — StyleX hashes it, so the curve is pinned by those longhands and the frames.

**A comment can leak a rule into the built CSS.** A first draft named `--animate-in` /
`--animate-out` while explaining the shorthand, and Tailwind's scanner added two lines to the
`@theme` block; both comments are reworded and the built CSS has neither name.

## Observed pre-existing defects

Nothing was fixed. In addition to the earlier rows' lists: **`data-inset={false}` indents like
`data-inset`** in both files, because React stringifies it and the variant is a bare `[data-inset]`
selector; **`ContextMenu` has no caller outside the gallery**; and **the two menus' icon rules have
drifted apart** (`focus:*:[svg]:` versus `not-data-…:focus:**:`).

## Findings for conventions.md

Not applied here; `conventions.md` is the orchestrator's.

1. **A comment may not name a theme variable**: `--animate-in` in one adds two `@theme` lines.
2. **`overflow` versus `overflow-y`**: StyleX ranks the shorthand below the longhand, inverting
   Tailwind's outcome, so a `data-*:overflow-hidden` beside it must go on the longhand.
3. **`dark:` nested inside an attribute key**, when both ask for one property (5000 versus 2040).
4. **Keyframes deduplicate across files by content**: no shared module needed for one animation.
