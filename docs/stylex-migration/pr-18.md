## Findings

- **`text-[8px]` emits no line height at all.** `conventions.md` records `text-[10px]` compiling to
  `font-size: 10px; line-height: var(--tw-leading)`; this build emits **only** `font-size: 8px`, so
  `AvatarFallback`'s `text-sm` ratio `calc(1.25 / 0.875)` re-resolves against 8px into an 11.43px
  line box, where a StyleX `lineHeight: '1.25rem'` would keep 20px at every size.
- **`group-data-…/name:` wraps the group class in `:where()`**: the emitted rule is
  `…:is(:where(.group\/avatar)[data-size=sm] *)`, so the file uses that shape (`IN_AVATAR_SM`) and
  the marker classes stay on the two roots.
- **Values.** `rounded-full` ships as `3.40282e38px` (computes to the clamped `3.35544e7px`),
  `aspect-square` is `aspect-ratio: 1`, `after:*` always writes `content`, and `after:border` writes
  `border-style: var(--tw-border-style)` (initial `solid`).

## Observed pre-existing defects (nothing was fixed)

- **`AvatarBadge` has no `xs` arm** — `sm`, `default` and `lg` each get a
  `group-data-[size=…]/avatar:size-*` rule, `xs` gets none, so an `xs` badge is sized by its content
  and spills out of a 16px avatar. Pinned by `navbits-avatar-badge-xs`.
- **`AvatarGroupCount`'s `group-has-data-[size=…]` rules read the _group_**, so a group holding both
  an `sm` and an `lg` avatar matches both at equal specificity and emission order decides; the
  migrated file writes the `lg` arm first, the order Tailwind emits them in.
- **`AvatarBadge`'s `bg-blend-color` does nothing** (no background image), **`NavUser` is dead code**,
  and **`oxfmt --check` already fails on `row-brief.md`** on the branch base. All left untouched.

## Findings for conventions.md

1. **`group-data-…/name:` and `group-has-data-…/name:` wrap the group class in `:where()`**; the
   faithful key is `:is(:where(.group\/name)[data-x="y"] *)`, one class below the table's form.
2. **An arbitrary `text-[Npx]` emits no line-height declaration at all**, a stronger reason to keep a
   paired `text-*` than the "invalid at computed-value time" shape already recorded: the ratio simply
   re-resolves against the new font size, so a component that overrides its own font size behind a
   variant has to keep all of its `text-*` classes Tailwind together.
3. **The Tailwind scanner reads prose.** A bare `shrink`, `block` or `container` as an English word
   inside a migrated file emits that utility. Quote class names; never let one stand alone.
4. **An `!important` caller-side utility cannot become an `sx` prop**: an `sx` wins the layer war
   too, but only by replacing the target's whole conditional declaration for that property.
5. **A `:focus-visible` ring on an anchor needs a real keyboard focus in the test** —
   `locator.focus()` does not set Chromium's heuristic, `focus()` → `Shift+Tab` → `Tab` does.
