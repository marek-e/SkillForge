## Findings

- **`marginBlockStart`/`marginBlockEnd` compile to physical `margin-top`/`margin-bottom`.**
  `space-y-2` on `ToolCard`'s body is `':is(*)>:not(:last-child)'` with the pair Tailwind emits and
  ships as `margin-top:0` / `margin-bottom:.5rem`. It still loses to `AccordionContent`'s
  `[&_p:not(:last-child)]:mb-4` — a utility outranks a `priorityN` rule whatever the selector — so
  the measured 16px gap is unchanged.
- **`@keyframes` dedupe across files**: `animate-pulse`'s body equals `skeleton.tsx`'s, so the sheet
  still holds 34 blocks, not 35.
- **Lightning CSS folds values Tailwind keeps behind a variable.** The literal
  `oklch(69.6% 0.17 162.48)` ships as `#00bb7f` + `lab(66.9756% -58.27 19.5419)` where Tailwind
  ships `var(--color-emerald-500)`, and `invert(100%)` ships as `invert()`. Pixels match (the
  `toolsx-compact-*` originals were taken on the Tailwind base); the computed string does not.
- **`text-[10px]` emits no usable line height** (`line-height: var(--tw-leading)`, no fallback), so
  the translation declares **no** `lineHeight` and the `kbd` inherits `InputGroupAddon`'s ratio
  (measured `14.2857px`). The `rounded` beside it was dead too: the addon's
  `[&>kbd]:rounded-[calc(var(--radius)-5px)]` makes the radius 5px, and StyleX loses where it lost.

## Observed pre-existing defects (nothing was fixed)

- **`ToolCard`'s `space-y-2` never applies between the command rows**: `AccordionContent`'s
  `[&_p:not(:last-child)]:mb-4` wins, so the gap is 16px, not 8px. Kept exactly; pinned by
  `toolsx-tool-card-accordion-target`.
- **`SkillLibraryFilterBar` swallows ⌘F/Ctrl+F document-wide** with no active-element check, its
  `isMac` reads the deprecated `navigator.platform` at module scope, and it labels two of three
  tools by their raw id (`claude`, `Cursor`, `openai`) because `getToolConfig` maps only some
  `originalTool` values. Untouched.
- **The detected dot's glow is a hard-coded `rgba(16, 185, 129, 0.4)`**, not a token, so it ignores
  the theme. Pinned as-is in both themes.

## Findings for conventions.md

- Lightning CSS folds a **literal** `oklch()` into `#hex` + `lab()` and `invert(100%)` into
  `invert()`, while the Tailwind rule keeps a `var(--color-*)`: pixels match, the computed string
  does not.
- StyleX emits `marginBlockStart`/`marginBlockEnd` as physical margins, so a `space-y-*` translation
  is equivalent only while the document stays `horizontal-tb`.
- When a font-size utility emits `line-height: var(--tw-leading)` with no fallback, **omit**
  `lineHeight` rather than compute one.
- Identical `stylex.keyframes` bodies dedupe to one `@keyframes` block across files, so a keyframe
  count does not tell you whether a row added an animation.
