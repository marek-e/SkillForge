# Final StyleX integration

Integrated on November 14, 2026, on `stylex-migration`. No merge to `main` or push is included.

## Scope

Recovered the uncommitted work in `pr-17`, `pr-25`, and `pr-31`, including the new test cases and originals. Verified patches, changed files, local databases, and manifests for all 20 old worktrees and the active checkout are saved under `/Users/mareke/Dev/Projects/SkillForge-worktree-backups/2026-11-14`. The old checkouts were removed on November 14, 2026; every local branch and commit was retained. Restore instructions are in the backup's `README.txt`.

Finished the sidebar, shell/titlebar, sidebar app components, home and settings routes. Converted the remaining component overrides and test gallery to StyleX. All styled overrides use typed `sx` channels, and foreign-element selectors compose separately from own-element overrides so a width override cannot erase icon sizing or child padding.

Removed Tailwind, its Vite plugin, `tw-animate-css`, `cva`, `clsx`, `tailwind-merge`, the `cn` helper, and the Tailwind generator configuration/CLI. The lockfile and installed dependencies were synchronized. The exact element reset remains in `styles/reset.css` with its MIT notice; theme values remain in `styles/global.css`. Font imports moved to `main.tsx` so dependency analysis can follow them. No owned component styling remains global.

`group`, `peer`, `size-explicit`, and `w-explicit` are semantic selector hooks. The few `border-b`, `border-t`, and `sr-only` markers preserve selectors that inspect class text; they generate no utility CSS. Transition-property lists still name the old gradient properties because their computed strings are part of the original contract, but no declaration reads a generated Tailwind variable.

Explicit-null variant behavior is preserved. Null omits a variant or size; undefined still selects its default. Sixteen focused checks cover the form/group variants, alongside the full visual matrix.
