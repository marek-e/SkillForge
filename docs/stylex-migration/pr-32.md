Font imports moved to `main.tsx` so dependency analysis can follow them. No owned component styling remains global.

`group`, `peer`, `size-explicit`, and `w-explicit` are semantic selector hooks. The few `border-b`, `border-t`, and `sr-only` markers preserve selectors that inspect class text; they generate no utility CSS. Transition-property lists still name the old gradient properties because their computed strings are part of the original contract, but no declaration reads a generated Tailwind variable.

Explicit-null variant behavior is preserved. Null omits a variant or size; undefined still selects its default. Sixteen focused checks cover the form/group variants, alongside the full visual matrix.
